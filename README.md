# 📦 SafeDrop

**SafeDrop** is an IoT-enabled smart locker system designed to secure package deliveries by seamlessly bridging physical hardware with a mobile application. 

Built with **React Native** and **Expo**, the application leverages strict **Role-Based Access Control (RBAC)**. This architecture allows the app to securely serve three distinct user types—such as couriers, customers, and administrators—all from a single, unified codebase.

### Key Features
* **Hardware Integration:** Connects mobile software with physical smart locker IoT endpoints.
* **Unified Codebase:** Serves multiple distinct user experiences through dynamic RBAC routing.
* **Cross-Platform:** Developed with React Native and Expo for simultaneous iOS and Android deployment.
